# E2 static (D-213): the theme art that does not move, Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Aurora, Norse and Vardr Labs their static art on both shells: rune tab icons and the three active-tab marks, the three raised + buttons, notched and framed cards, diamond and square tiles, the Norse avatar ring, the ᛟ section mark, the theme-aware meta separator, titles in each theme's display face with the Norse ornament on five screens, Vardr Labs' outlined main button and its dot-grid ground; every new colour pair measured.

**Architecture:** One new file per shell (`ThemeArt.swift`, `ThemeArt.kt`) holds the runes, the art's colours and sizes, the pure geometry (vertex lists the shapes draw) and the per-theme decisions (`TabIndicator`, `AddButtonArt`, `CardStyle`, `TileShape`, `ButtonLook`, `Ground`, `SectionMark`, `Separator`). The shared components screens already use (`SkiptiTabBar`, `glassCard`, `PictureTile`, `PersonAvatar`, `AvatarView`, the button styles, `auroraBackground`) read those decisions; no screen is rewritten. Titles change once, centrally: iOS sets the navigation bar's title attributes on every live bar when the appearance changes; Android's five tab-root titles take a new `Type.title`. An Android parity test reads `ThemeArt.swift` and compares every value with `ThemeArt.kt`.

**Tech Stack:** SwiftUI + UIKit (iOS 17 target), Core Text (the rune font check); Jetpack Compose; Python 3 (`.drafts/d213/art.py`, the measurements). No new dependency, no bundled font, no core change.

**Spec:** `docs/superpowers/specs/2026-10-15-e2-theme-art-design.md` section 1 (approved 2026-10-15). Read it first. Visual reference: the Look Book v2.1, `.drafts/lookbook/skipti-lookbook.html` (rules `.t-norse ...` and `.t-vardr ...`, lines 215 to 285), and the titles demo `.drafts/e2/titles-mock.html` (option A).

**Branch:** `e2-static` from main `4d31046` (or the commit that adds this plan). D-number **D-213**. Drafts in `.drafts/d213/`.

## Decisions taken in this plan (implementation calls; record each in the D-213 row)

1. **The ᛟ mark goes on section labels only, through a new opt-in API** (iOS `.sectionLabel()`, Android `SectionLabel(...)`). About a third of today's `microLabelFont` / `Type.kicker` sites are not section labels (status words, hints, row flags); a mark inside `microLabelFont` / `kicker` itself, as the spec's "Where" column says, would put ᛟ before "On", "Showing" and whole sentences. The rule and the exclusion list are in Task 5.
2. **Tiles and avatars:** "Tiles (group, person)" are `PictureTile` (a group) and `PersonAvatar`'s initial on a tone (a person without a picture): Norse diamond, Vardr Labs square, Aurora as now (group rounded at size x 0.3, person circle). `AvatarView` (a picture slot: a photo, an emoji, or your own initials) stays a circle in every theme, with the 1 pt `#4A3F24` ring in Norse and its initials in Cormorant SC in Norse. This matches the Look Book's `.avatar` (round, ringed in Norse).
3. **Styled separators:** the ᛫ takes the accent where a body draws the joined line in a `Text` itself (`Separator.text` / `Separator.annotated`); a join that produces a `String` (a copy function, an interpolated sentence, a section label's text) uses the plain `Separator.meta`.
4. **The Vardr Labs light bolt** follows the Look Book's light stops (above).
5. **The Vardr Labs light tab outline** is 0.75 (the nudge above).
6. **The + glyph's floor** is measured under the glyph, not on the lightest stop (above).
7. **Android rune check:** JVM tests cannot load the phone's fonts (no Robolectric, no instrumented tests in the gate), so `Paint.hasGlyph` runs in a debug-only proof surface, `--es args --rune-proof`, read during the look (Task 4). The gate does not cover it; record that in §4.
8. **Android's raw accent buttons** (seven `Button(colors = buttonColors(containerColor = Tok.accent...))` sites) move to `PrimaryAction`, so Vardr Labs' outline reaches them; `PrimaryAction` gains a `modifier` parameter.

import CoreText
import SwiftUI
import UIKit

@testable import Skipti

/// D-213 (E2, ADR-0041 "Theme art"): the static art's data, geometry and
/// per-theme decisions. Goldens are worked by hand (see each test); the
/// colours and sizes are checked against .drafts/d213/art.py. Android's twin
/// is ThemeArtTest.
final class ThemeArtTests: XCTestCase {
    /// The spec's glyph table, by code point (re-derived from the Look Book's FUTHARK string with Python's
    /// unicodedata: RUNIC LETTER FEHU 16A0 ... OTHALAN 16DF, SINGLE PUNCTUATION 16EB).
    func testTheGlyphTableIsTheSpecs() {
        func cp(_ s: String) -> [UInt32] { s.unicodeScalars.map(\.value) }
        XCTAssertEqual(cp(Runes.balance), [0x16A0])
        XCTAssertEqual(cp(Runes.expenses), [0x16B7])
        XCTAssertEqual(cp(Runes.groups), [0x16D7])
        XCTAssertEqual(cp(Runes.settle), [0x16CF])
        XCTAssertEqual(cp(Runes.separator), [0x16EB])
        XCTAssertEqual(cp(Runes.sectionMark), [0x16DF])
        XCTAssertEqual(cp(Runes.ornament), [0x16DC])
        XCTAssertEqual(Runes.futhark.flatMap(cp), [
            0x16A0, 0x16A2, 0x16A6, 0x16A8, 0x16B1, 0x16B2, 0x16B7, 0x16B9, 0x16BA, 0x16BE, 0x16C1, 0x16C3,
            0x16C7, 0x16C8, 0x16C9, 0x16CA, 0x16CF, 0x16D2, 0x16D6, 0x16D7, 0x16DA, 0x16DC, 0x16DE, 0x16DF,
        ])
        XCTAssertEqual(Runes.all.count, 25)
        XCTAssertEqual(HomeTab.allCases.map(\.rune), [Runes.balance, Runes.expenses, Runes.groups, Runes.settle])
    }

    /// No font is bundled: the system must draw every rune, from a real font (not LastResort's boxes).
    private func systemDraws(_ s: String) -> Bool {
        let base = UIFont.systemFont(ofSize: 17) as CTFont
        let cf = s as CFString
        let font = CTFontCreateForString(base, cf, CFRange(location: 0, length: CFStringGetLength(cf)))
        if (CTFontCopyPostScriptName(font) as String) == "LastResort" { return false }
        var chars = Array(s.utf16)
        var glyphs = [CGGlyph](repeating: 0, count: chars.count)
        return CTFontGetGlyphsForCharacters(font, &chars, &glyphs, chars.count) && !glyphs.contains(0)
    }

    func testEveryRuneDrawsFromASystemFont() {
        for rune in Runes.all {
            XCTAssertTrue(systemDraws(rune), "U+\(String(rune.unicodeScalars.first?.value ?? 0, radix: 16, uppercase: true)) has no system glyph")
        }
    }

    /// The negative: U+16F9 is unassigned (the Runic block ends at U+16F8), so the check must refuse it.
    func testTheFontCheckRefusesAnUnassignedCodePoint() {
        XCTAssertFalse(systemDraws("\u{16F9}"))
    }

    /// Hand-worked: a 100 x 60 card with an 8 pt chamfer.
    func testTheNotchedCardsVertices() {
        let p = ArtGeometry.notched(CGRect(x: 0, y: 0, width: 100, height: 60), chamfer: 8)
        XCTAssertEqual(p, [CGPoint(x: 8, y: 0), CGPoint(x: 92, y: 0), CGPoint(x: 100, y: 8), CGPoint(x: 100, y: 52),
                           CGPoint(x: 92, y: 60), CGPoint(x: 8, y: 60), CGPoint(x: 0, y: 52), CGPoint(x: 0, y: 8)])
    }

    /// The negative: a chamfer larger than half the short side is clamped to it (10 x 10 -> 5).
    func testTheChamferNeverPassesHalfTheShortSide() {
        let p = ArtGeometry.notched(CGRect(x: 0, y: 0, width: 10, height: 10), chamfer: 8)
        XCTAssertEqual(p, [CGPoint(x: 5, y: 0), CGPoint(x: 5, y: 0), CGPoint(x: 10, y: 5), CGPoint(x: 10, y: 5),
                           CGPoint(x: 5, y: 10), CGPoint(x: 5, y: 10), CGPoint(x: 0, y: 5), CGPoint(x: 0, y: 5)])
    }

    /// The diamond's tips are the box's edge midpoints: top, right, bottom, left.
    func testTheDiamondsVertices() {
        XCTAssertEqual(ArtGeometry.diamond(CGRect(x: 0, y: 0, width: 48, height: 48)),
                       [CGPoint(x: 24, y: 0), CGPoint(x: 48, y: 24), CGPoint(x: 24, y: 48), CGPoint(x: 0, y: 24)])
    }

    /// The Look Book's clip-path on 72 x 64: 0.02 x 64 = 1.28, 0.98 x 64 = 62.72.
    func testTheHexagonsVertices() {
        let p = ArtGeometry.hexagon(CGRect(x: 0, y: 0, width: 72, height: 64))
        let want = [CGPoint(x: 18, y: 1.28), CGPoint(x: 54, y: 1.28), CGPoint(x: 72, y: 32),
                    CGPoint(x: 54, y: 62.72), CGPoint(x: 18, y: 62.72), CGPoint(x: 0, y: 32)]
        XCTAssertEqual(p.count, want.count)
        for (a, b) in zip(p, want) {
            XCTAssertEqual(a.x, b.x, accuracy: 0.0001)
            XCTAssertEqual(a.y, b.y, accuracy: 0.0001)
        }
    }

    /// Eight 8 pt strokes, 3 pt in from each corner of a 100 x 60 card, every point inside the card.
    func testTheFrameMarks() {
        let rect = CGRect(x: 0, y: 0, width: 100, height: 60)
        let s = ArtGeometry.frameMarks(rect, inset: 3, length: 8)
        XCTAssertEqual(s.count, 8)
        let want: [(CGPoint, CGPoint)] = [
            (CGPoint(x: 3, y: 3), CGPoint(x: 11, y: 3)), (CGPoint(x: 3, y: 3), CGPoint(x: 3, y: 11)),
            (CGPoint(x: 97, y: 3), CGPoint(x: 89, y: 3)), (CGPoint(x: 97, y: 3), CGPoint(x: 97, y: 11)),

/// D-213: the art's shapes as vertex lists (testable), drawn by the shapes below.
enum ArtGeometry {
    /// A rectangle with each corner cut at `chamfer` (clamped to half the short side).
    static func notched(_ r: CGRect, chamfer: CGFloat) -> [CGPoint] {
        let c = min(chamfer, min(r.width, r.height) / 2)
        return [
            CGPoint(x: r.minX + c, y: r.minY), CGPoint(x: r.maxX - c, y: r.minY),
            CGPoint(x: r.maxX, y: r.minY + c), CGPoint(x: r.maxX, y: r.maxY - c),
            CGPoint(x: r.maxX - c, y: r.maxY), CGPoint(x: r.minX + c, y: r.maxY),
            CGPoint(x: r.minX, y: r.maxY - c), CGPoint(x: r.minX, y: r.minY + c),
        ]
    }

    /// The box's edge midpoints: a square turned 45 degrees, drawn upright.
    static func diamond(_ r: CGRect) -> [CGPoint] {
        [CGPoint(x: r.midX, y: r.minY), CGPoint(x: r.maxX, y: r.midY),
         CGPoint(x: r.midX, y: r.maxY), CGPoint(x: r.minX, y: r.midY)]
    }

    /// The Look Book's bolt head (its clip-path).
    static func hexagon(_ r: CGRect) -> [CGPoint] {
        [(0.25, 0.02), (0.75, 0.02), (1, 0.5), (0.75, 0.98), (0.25, 0.98), (0, 0.5)].map {
            CGPoint(x: r.minX + r.width * $0.0, y: r.minY + r.height * $0.1)
        }
    }

    /// Eight strokes: an L at each corner, `inset` in, each arm `length` long.
    static func frameMarks(_ r: CGRect, inset i: CGFloat, length l: CGFloat) -> [(CGPoint, CGPoint)] {
        let (x0, y0, x1, y1) = (r.minX + i, r.minY + i, r.maxX - i, r.maxY - i)
        return [
            (CGPoint(x: x0, y: y0), CGPoint(x: x0 + l, y: y0)), (CGPoint(x: x0, y: y0), CGPoint(x: x0, y: y0 + l)),
            (CGPoint(x: x1, y: y0), CGPoint(x: x1 - l, y: y0)), (CGPoint(x: x1, y: y0), CGPoint(x: x1, y: y0 + l)),
            (CGPoint(x: x1, y: y1), CGPoint(x: x1 - l, y: y1)), (CGPoint(x: x1, y: y1), CGPoint(x: x1, y: y1 - l)),
            (CGPoint(x: x0, y: y1), CGPoint(x: x0 + l, y: y1)), (CGPoint(x: x0, y: y1), CGPoint(x: x0, y: y1 - l)),
        ]
    }

    /// A dot at the centre of each `pitch` cell whose centre lies inside `size`.
    static func gridDots(_ size: CGSize, pitch: CGFloat) -> [CGPoint] {
        guard pitch > 0 else { return [] }
        var dots: [CGPoint] = []
        var y = pitch / 2
        while y < size.height {
            var x = pitch / 2
            while x < size.width {
                dots.append(CGPoint(x: x, y: y))
                x += pitch
            }
            y += pitch
        }
        return dots
    }

    /// A closed polygon; with `radius` > 0 each corner is rounded by a curve that starts `radius` along each edge.
    static func roundedPolygon(_ p: [CGPoint], radius r: CGFloat) -> Path {
        var path = Path()
        guard p.count > 2 else { return path }
        func toward(_ a: CGPoint, _ b: CGPoint) -> CGPoint {
            let dx = b.x - a.x, dy = b.y - a.y
            let len = max(hypot(dx, dy), .ulpOfOne)
            let t = min(r, len / 2) / len
            return CGPoint(x: a.x + dx * t, y: a.y + dy * t)
        }
        for i in p.indices {
            let v = p[i], prev = p[(i + p.count - 1) % p.count], next = p[(i + 1) % p.count]
            let a = toward(v, prev), b = toward(v, next)
            if i == 0 { path.move(to: a) } else { path.addLine(to: a) }
            if r > 0 { path.addQuadCurve(to: b, control: v) } else { path.addLine(to: b) }
        }
        path.closeSubpath()
        return path
    }
}

struct NotchedRectangle: Shape {

}

struct Diamond: Shape {
    var radius: CGFloat = 0

}

struct Hexagon: Shape {

/** D-213: the art's shapes as vertex lists (testable on the JVM); the twin of iOS's ArtGeometry. */
object ArtGeometry {
    fun notched(w: Float, h: Float, chamfer: Float): List<Offset> {
        val c = min(chamfer, min(w, h) / 2)
        return listOf(
            Offset(c, 0f), Offset(w - c, 0f), Offset(w, c), Offset(w, h - c),
            Offset(w - c, h), Offset(c, h), Offset(0f, h - c), Offset(0f, c),
        )
    }

    fun diamond(w: Float, h: Float): List<Offset> = listOf(Offset(w / 2, 0f), Offset(w, h / 2), Offset(w / 2, h), Offset(0f, h / 2))

    fun hexagon(w: Float, h: Float): List<Offset> =
        listOf(0.25f to 0.02f, 0.75f to 0.02f, 1f to 0.5f, 0.75f to 0.98f, 0.25f to 0.98f, 0f to 0.5f).map { Offset(w * it.first, h * it.second) }

    fun frameMarks(w: Float, h: Float, inset: Float, length: Float): List<Pair<Offset, Offset>> {
        val (x0, y0, x1, y1) = listOf(inset, inset, w - inset, h - inset)
        return listOf(
            Offset(x0, y0) to Offset(x0 + length, y0), Offset(x0, y0) to Offset(x0, y0 + length),
            Offset(x1, y0) to Offset(x1 - length, y0), Offset(x1, y0) to Offset(x1, y0 + length),
            Offset(x1, y1) to Offset(x1 - length, y1), Offset(x1, y1) to Offset(x1, y1 - length),
            Offset(x0, y1) to Offset(x0 + length, y1), Offset(x0, y1) to Offset(x0, y1 - length),
        )
    }

    fun gridDots(w: Float, h: Float, pitch: Float): List<Offset> {
        if (pitch <= 0f) return emptyList()
        val dots = mutableListOf<Offset>()
        var y = pitch / 2
        while (y < h) {
            var x = pitch / 2
            while (x < w) {
                dots += Offset(x, y)
                x += pitch
            }
            y += pitch
        }
        return dots
    }

    /** A closed polygon; with [radius] > 0 each corner is rounded by a curve that starts [radius] along each edge. */
    fun roundedPolygon(p: List<Offset>, radius: Float): Path {
        val path = Path()
        if (p.size < 3) return path
        fun toward(a: Offset, b: Offset): Offset {
            val dx = b.x - a.x
            val dy = b.y - a.y
            val len = hypot(dx, dy).coerceAtLeast(1e-6f)
            val t = min(radius, len / 2) / len
            return Offset(a.x + dx * t, a.y + dy * t)
        }
        p.indices.forEach { i ->
            val v = p[i]
            val a = toward(v, p[(i + p.size - 1) % p.size])
            val b = toward(v, p[(i + 1) % p.size])
            if (i == 0) path.moveTo(a.x, a.y) else path.lineTo(a.x, a.y)
            if (radius > 0f) path.quadraticTo(v.x, v.y, b.x, b.y) else path.lineTo(b.x, b.y)
        }
        path.close()
        return path
    }
}

fun tileShape(shape: TileShape, size: Int): Shape = when (shape) {
    TileShape.ROUNDED -> RoundedCornerShape((size * 0.3f).dp)
    TileShape.CIRCLE -> CircleShape
    TileShape.DIAMOND -> DiamondShape(ThemeArt.m("tileRadius").dp)
    TileShape.SQUARE -> RectangleShape

/** The raised +'s face per theme; the twin of iOS's AddButtonFace. The glyph is the set's `onAccent`. */
@Composable
fun AddButtonFace(art: AddButtonArt, dark: Boolean, modifier: Modifier = Modifier) {
    val glyph: @Composable () -> Unit = {
        Icon(imageVector = TabIcons.Plus, contentDescription = null, tint = Tok.onAccent(dark), modifier = Modifier.size(28.dp))
    }
    when (art) {
        AddButtonArt.CIRCLE -> Box(
            modifier
                .shadow(10.dp, CircleShape, spotColor = Tok.accent(dark))
                .size(64.dp)
                .background(Tok.accent(dark), CircleShape)
                .border(4.dp, Tok.bg(dark), CircleShape),
            contentAlignment = Alignment.Center,
        ) { glyph() }
        AddButtonArt.DIAMOND -> {
            val shape = DiamondShape(ThemeArt.m("diamondRadius").dp)
            val side = (ThemeArt.m("diamondSide") * kotlin.math.sqrt(2f)).dp
            Box(
                modifier
                    .shadow(7.dp, shape)
                    .size(side)
                    .background(Brush.verticalGradient(listOf(ThemeArt.color("diamondTop"), ThemeArt.color("diamondBottom"))), shape)
                    .border(4.dp, Tok.bg(dark), shape),
                contentAlignment = Alignment.Center,
            ) { glyph() }
        }
        AddButtonArt.BOLT -> {
            val w = ThemeArt.m("boltWidth")
            val h = ThemeArt.m("boltHeight")
            val stops = ThemeArt.boltStops(dark).toTypedArray()
            Box(
                modifier
                    .size(w.dp, h.dp)
                    .drawBehind {
                        val brush = Brush.linearGradient(
                            *stops,
                            start = Offset(size.width * ThemeArt.m("boltStartX"), size.height * ThemeArt.m("boltStartY")),
                            end = Offset(size.width * ThemeArt.m("boltEndX"), size.height * ThemeArt.m("boltEndY")),
                        )
                        drawPath(ArtGeometry.roundedPolygon(ArtGeometry.hexagon(size.width, size.height), 0f), brush)
                        drawCircle(Color.White.copy(alpha = ThemeArt.reticleAlpha(dark)), radius = size.height / 3, style = Stroke(1.dp.toPx()))
                    },
                contentAlignment = Alignment.Center,
            ) { glyph() }
        }
    }
}

enum TitleStyle {
    /// The Look Book's `.title`: 700 (Vardr Labs 600).
    static func weight(_ theme: AppTheme) -> CGFloat { theme == .vardr ? 600 : 700 }

    /// The Look Book's tracking in em: -0.01; Norse +0.03; Vardr Labs -0.02.
    static func tracking(_ theme: AppTheme) -> CGFloat {
        switch theme {
        case .aurora: return -0.01
        case .norse: return 0.03
        case .vardr: return -0.02
        }

    /// The system's sizes (large 34, inline 17), scaled for SKIPTI's text size.
    static func font(large: Bool, theme: AppTheme, category: UIContentSizeCategory) -> UIFont {
        let base = TypeRole.base(TypeRole.face(.display, theme: theme), size: large ? 34 : 17, weight: weight(theme), tabular: false)
        return UIFontMetrics(forTextStyle: large ? .largeTitle : .headline)
            .scaledFont(for: base, compatibleWith: UITraitCollection(preferredContentSizeCategory: category))
    }

    static func attributes(large: Bool, theme: AppTheme, category: UIContentSizeCategory) -> [NSAttributedString.Key: Any] {
        let f = font(large: large, theme: theme, category: category)
        return [.font: f, .kern: f.pointSize * tracking(theme), .foregroundColor: Tokens.uiColor("text")]
    }

    /// Every bar already on screen, and the appearance proxy for bars made later (a sheet's own stack).
    @MainActor
    static func apply(_ state: AppearanceState, to window: UIWindow) {
        let large = attributes(large: true, theme: state.theme, category: state.contentSizeCategory)
        let inline = attributes(large: false, theme: state.theme, category: state.contentSizeCategory)
        let proxy = UINavigationBar.appearance()
        proxy.largeTitleTextAttributes = large
        proxy.titleTextAttributes = inline
        for bar in navigationBars(in: window.rootViewController) {
            bar.largeTitleTextAttributes = large
            bar.titleTextAttributes = inline
        }

    static func navigationBars(in root: UIViewController?) -> [UINavigationBar] {
        guard let root else { return [] }
        var bars: [UINavigationBar] = []
        if let nav = root as? UINavigationController { bars.append(nav.navigationBar) }
        for child in root.children { bars += navigationBars(in: child) }
        if let presented = root.presentedViewController, presented !== root.parent { bars += navigationBars(in: presented) }
        return bars
    }

object SectionLabels {
    fun annotated(text: String, theme: AppTheme = Appearance.theme): AnnotatedString = buildAnnotatedString {
        SectionMark.prefix(theme)?.let { withStyle(SpanStyle(color = Tok.accent.norse, letterSpacing = 0.sp)) { append(it) } }

    }
}

@Composable

    val marked = SectionMark.prefix(Appearance.theme) != null

        style = Type.microLabel(dark).copy(color = color),
        modifier = if (marked) modifier.semantics { contentDescription = text } else modifier,
    )
}
