# Re-tap a tab (D-205) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tapping the tab you are in takes you to that tab's first screen; tapping it again there scrolls to the top (spec: `docs/superpowers/specs/2026-10-13-feedback-round-design.md`, section B).

**Architecture:** One pure rule, `TabTap.decide(selected:tapped:covered:)`, twinned on both shells and tested. iOS: the shell rebuilds a tab's `NavigationStack` with a per-tab `.id` token (pop to root) or bumps a per-tab scroll token that a `shellScrollTop()` modifier on each root screen answers. Android already returns to the root on any tab tap (`openGroup = null` in `onSelect`), so it gains only the rule and scroll-to-top, through `rememberShellScrollState()` and a `LocalScrollTop` composition local.

**Tech Stack:** SwiftUI (iOS 17+), Jetpack Compose, XCTest, JUnit.

## Global Constraints

- Twins: identical behaviour, labels and order on iOS and Android (CLAUDE.md §10); the one existing asymmetry (Android's tab switch also closes a group page) stays and is recorded in §4.
- No new dependency. No new Swift file (no pbxproj edit): code goes in existing files.
- Reduce Motion: iOS animates only when `accessibilityReduceMotion` is off; Compose's `animateScrollTo` follows the system animator scale.
- The raised + is not a tab and is unchanged.

- [ ] **Step 3: Implement the Swift rule** (after the closing `}` of `struct SkiptiTabBar`, before `/// The + shrinks…` or the next type)

```swift
/// D-205 (the founder, 2026-10-13): what a tap on a tab does. UIKit's own
/// tab bar rule, which SKIPTI's custom bar (D-179) had lost: the tab you are
/// in goes back to its first screen, and there a tap scrolls to the top.
/// `covered` is ShellChrome's set of tabs with a page pushed over the root.
/// Android's twin is TabTap in TabBar.kt.
enum TabTap: Equatable {
    case switchTo(HomeTab)
    case popToRoot(HomeTab)
    case scrollToTop(HomeTab)

    static func decide(selected: HomeTab, tapped: HomeTab, covered: Set<HomeTab>) -> TabTap {
        guard tapped == selected else { return .switchTo(tapped) }
        return covered.contains(tapped) ? .popToRoot(tapped) : .scrollToTop(tapped)
    }
}
```

```kotlin
/** D-205 (the founder, 2026-10-13): what a tap on a tab does; the twin of
 *  iOS's TabTap. The tab you are in goes back to its first screen, and there
 *  a tap scrolls to the top. `covered`: tabs with a page open over the root. */
sealed interface TabTap {
    data class SwitchTo(val tab: HomeTab) : TabTap
    data class PopToRoot(val tab: HomeTab) : TabTap
    data class ScrollToTop(val tab: HomeTab) : TabTap

    companion object {
        fun decide(selected: HomeTab, tapped: HomeTab, covered: Set<HomeTab>): TabTap = when {
            tapped != selected -> SwitchTo(tapped)
            tapped in covered -> PopToRoot(tapped)
            else -> ScrollToTop(tapped)
        }
    }
}
```

```swift
/// D-205: a tab root's scroll content: back to the top when its tab is
/// tapped again at the root (ShellChrome.scrollTop).
private struct ShellScrollTop: ViewModifier {
    @Environment(\.shellTab) private var tab
    @Environment(\.shellChrome) private var chrome
    @Environment(\.accessibilityReduceMotion) private var reduceMotion

    private var signal: Int { tab.flatMap { chrome?.scrollTop[$0] } ?? 0 }

    func body(content: Content) -> some View {
        ScrollViewReader { proxy in
            content
                .id(ShellBar.top)
                .onChange(of: signal) {
                    if reduceMotion {
                        proxy.scrollTo(ShellBar.top, anchor: .top)
                    } else {
                        withAnimation(.easeInOut(duration: 0.3)) { proxy.scrollTo(ShellBar.top, anchor: .top) }
                    }
                }
        }
    }
}
```

```kotlin
/** D-205: bumped when the shown tab is tapped again at its first screen. */
val LocalScrollTop = compositionLocalOf { 0 }

/** A tab root's scroll state: back to the top when [LocalScrollTop] changes. */
@Composable
fun rememberShellScrollState(): ScrollState {
    val state = rememberScrollState()
    val signal = LocalScrollTop.current
    LaunchedEffect(signal) { if (signal > 0) state.animateScrollTo(0) }
    return state
}
```
