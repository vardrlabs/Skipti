## Design

1. **Stroke (L18).** One constant per shell: Swift `enum LucideStroke { static let width: CGFloat = 2.4; static let plus:
   CGFloat = 2.8 }` in `LucideIcon.swift`, Kotlin `object LucideStroke { const val WIDTH = 2.4f; const val PLUS = 2.8f }`
   in `TabIcons.kt`; Android's test reads the Swift file and compares. Every Lucide draw reads it: iOS `LucideIcon`
   (new parameter `stroke: CGFloat = LucideStroke.width`, line width `stroke * size / 24`), `LucideGlyph.stroke(in:color:)`
   (`templateImage`, `inkImage`) and `inkImage`'s ink inset (half the stroke, was a literal 1); Android every
   `TabIcons` vector and the notification icon `ic_stat_bell.xml` (`android:strokeWidth="2.4"`). Path data is unchanged,
   so NOTICE and `native/licences/licences.json` do not change.
   **DECIDED (controller, for the founder): the + glyph takes 2.8**, because the Look Book draws its plus at
   `stroke-width:2.8` inline (LB 335, `.pi`), heavier than the other icons; only the + uses `LucideStroke.plus`.
   **Chevrons (D-217) still hold:** `BarTint.backChevronScale` stays 1.25 (the centreline is 12 units = 15 pt, the SF
   chevron's height); the back indicator image grows from (12 + 2) x 1.25 = 17.5 to (12 + 2.4) x 1.25 = 18.0 pt tall and
   from 10.0 to 10.5 pt wide, so `testTheBackChevronIsLucide` moves to the stroke-derived goldens. `RowChevron` stays 20
   (its line goes 1.67 to 2.0 pt). Android's back `Icon` (22 dp) and `RowChevron` take the stroke from the vector.
   **Tab rune centring still holds:** `tabRune` 34 and `runeInkShiftEm` 0.025 measure the Vardr Runes font's ink, not
   a stroke; nothing in this unit touches them, and `testTheTabRunesFillTheirSlotByTheirInk` /
   `the_tab_runes_fill_their_slot_by_their_ink` must stay green unchanged.
2. **Aurora active tab (L13).** `TabIndicator.activeGlyph(theme)` returns `TabGlyphTint` (`.onAccent` Aurora, `.accent`
   Norse, `.ring` Vardr Labs); it replaces `glyphUsesRing`. Aurora's pill fills `accent` when on (was `accentSoft`). The
   label stays `text` when on. Measured: onAccent on accent 5.30 / 11.87; the accent pill on the glass bar 5.15 / 11.14
   minimum (3:1, art.py section 10).
3. **Bar ground (L15).** `enum TabBarGround { glass, solid }`, `of(theme)`: Aurora glass, Norse and Vardr Labs solid.
   Glass keeps each shell's film (iOS `.ultraThinMaterial` under `surface` at 0.72; Android `surface` at 0.94, no blur:
   C2). Solid is `surface`, opaque. A 1 pt / 1 dp `hairline` rule at the bar's top in every theme on both shells.
   **DECIDED (controller, for the founder): solid = the existing `surface` token, not a new `solid` token**, because the
   Look Book's `--p-solid` equals `surface` in Vardr Labs light and dark and differs by 3/255 in Norse (#0F0F11 against
   #121214); every label and glyph pair on it is already a measured pair (art.py section 11: text 13.89 or more, textDim
   6.80 or more). S1 and E3 (mode control, slider thumb, toast) may add a `solid` token through palette.py if Aurora
   dark's #0D1620 against #101A24 matters there.
4. **The +'s footprint (found while planning L17).** Today the + face's own box sets the bar row's height: 64 for the
   circle and the bolt, 70.71 for Norse's diamond, so Norse's bar is 6.7 pt taller than the others and taller than
   `ShellBar.reserved` (72 = 70 + 2), and the last row of a Norse tab root sits under it. Every face is now laid out in
   one 64 x 64 footprint (`AddButtonGeometry.footprint`) and drawn centred on it, overflowing; the lift stays 18. Every
   bar is 70 tall (6 + 64) in every theme; every face's centre is 50 above the row bottom.
5. **Diamond (L17).** `diamondSide` 64 (LB 115 and 238: the circle's square, turned). Its box is 64 x sqrt(2) = 90.51;
   top 95.25 above the row bottom (25.25 over the bar top, against the circle's 12 and today's diamond 12), bottom tip
   4.75 above the row bottom. Reach 45.25 from the + centre; the neighbour's glyph (22 at 1.08) starts 49.72 away at a
   320-wide bar, so it never touches (art.py section 12). Gradient, radius 6, the 4 pt `bg` edge and the shadow stay.
6. **Shadow (L16).** The circle takes the diamond's neutral shadow: iOS `Color.black.opacity(0.2)`, radius 7, y 6
   (the Look Book's `0 6px 14px rgba(0,0,0,.2)`, as D-213 converted it for the diamond); Android elevation 7 dp with
   the default (black) shadow colours, no `spotColor`. Shared constants: Swift `enum AddButtonShadow { alpha 0.2,
   radius 7, y 6 }`, Kotlin `object AddButtonShadow { const val ELEVATION = 7f }`. The bolt keeps no shadow (LB
   `box-shadow: none`).
7. **Reticle (L14).** SKIPTI's own drawing from the Look Book (LB 335 `.vp`), not a Lucide icon (no NOTICE change): arms
   `M3.5 12h5.5M15 12h5.5M12 3.5V9M12 15v5.5` stroked at `LucideStroke.width` with round caps and joins, and the centre
   dot r 1.3 FILLED, written as an arc path `M10.7 12a1.3 1.3 0 1 0 2.6 0a1.3 1.3 0 1 0-2.6 0` so both shells draw it
   from the same two strings (`ReticleGlyph.arms`, `ReticleGlyph.dot`). Size `reticleGlyph` 32 (LB 24 px on the 54 px
   bolt, x 72/54). Colour `onAccent` (unchanged; art.py section 7 at 32: lowest 3.85, Vardr Labs light). It turns with the
   bolt (it is inside the rotated face). Circle and diamond keep Lucide's plus at 28.
