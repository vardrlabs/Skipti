# D-215 Vardr Runes and IBM Plex Sans Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Both phones draw the same type: our own Vardr Runes (Carved) for Norse's runes and IBM Plex Sans in place of the system face, bundled identically on iOS and Android.

**Architecture:** Part A builds Vardr Runes in the private repo `vardrlabs/fonts` from one stroke table (`source/runes.json`) that drives both the specimen page and a fontTools build (12 TTFs). Part B bundles Vardr Runes Carved Regular and IBM Plex Sans (IBM's unmodified files) into SKIPTI, replaces every use of the system face for visible text, gives runes their own type role and attributes, and pins every file by sha256 on both shells.

**Tech Stack:** Python 3.14 + fontTools 4.53.1 (only in `vardrlabs/fonts/.venv`), SwiftUI / UIKit / Core Text (iOS), Jetpack Compose (Android), `scripts/licences.py`.

Spec: `docs/superpowers/specs/2026-10-15-d215-vardr-runes-plex-sans-design.md` (approved 2026-10-15).

## Global Constraints

- iPhone and Android must look identical, type included (CLAUDE.md Twins); no system font for visible text.
- Vardr Runes: OFL 1.1 with Reserved Font Name "Vardr"; family "Vardr Runes Carved" / "Vardr Runes Machined" / "Vardr Runes Circuit", subfamilies Light, Regular, Medium, Bold (strokes 62, 82, 100, 128 units); units per em 1000, cap height 700, baseline 0; version 1.000; the whole Runic block U+16A0 to U+16F8 (89 code points).
