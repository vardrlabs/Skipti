> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make iOS and Android draw, say and do the same in every item of `.drafts/d234/list.md` that this unit builds (the founder's A1 and A2, the width test T1, and the looks' findings L1 to L14), and record honestly what moves to 0.5.1 or stays as residue.

**Architecture:** Each fix is a small pure decision (tested on both shells, with parity tests that read the other shell's source where words or values are shared) plus the screen code that uses it. **Tech Stack:** SwiftUI (iOS 17+, XCTest hosted in the app), Jetpack Compose 1.12 / material3 1.4 (JUnit 4 JVM tests, no Robolectric; `java.awt` for font measurement), Python 3 stdlib for the sabotage runner. No new dependency.

**Spec:** `.drafts/d234/spec.md` (binding; decisions 80 to 99 for the controller to confirm or overturn; 79 is D-233's). Branch `d234-twin-fixes`, cut by the controller (Task 0). Implementers never switch branches.

## Global Constraints

- Twins (CLAUDE.md 10): the same behaviour, labels, order, copy and LOOK on both phones; a visible difference is a defect unless truly impossible, then recorded as residue with the reason.
- Copy is public: no em dash (U+2014) or en dash (U+2013) in any string, comment or doc this unit writes. Apostrophes are ASCII (`can't`), as the app's existing copy.
- New copy, verbatim on both shells: "Lunch at Shake Shack" and `$48.00` (core-formatted, USD); "A tap when it is done"; "Apple" / "Google" / "Email" on You's row; "expanded" / "collapsed"; "You can't add to your groups from this phone. Make a new group on Groups to add one."; "Nothing to settle from this phone. Your groups here can't take new records."
- Money: integer minor units from core, never a float, never shell-side formatting (`ffiMoneyParseMinor` then `ffiMoneyFormat`).
- Motion (D-231's door): every new animation snaps under Less motion, Reduce Motion / remove animations, or Low Power / battery saver: iOS `MotionClock.shouldTick(reduceMotion:lowPower:active:)` or `withAnimation(nil)`; Android `val motion = rememberMotionState()`, `val still = motion.reduce || motion.lowPower` or `val reduce = rememberMotionState().reduce`, specs `if (still) snap() else ...`, `AnimatedVisibility` enter and exit `if (still) EnterTransition.None / ExitTransition.None else ...`, animated scrolls `if (reduce) scroll.scrollTo(x) else scroll.animateScrollTo(x)` on one line. Never `repeatForever`.
- Values come from the generators, never by hand: the expand reuses `ThemeArt.m("switchTravel")` (0.2 s); no new art value.
- Tests owe more than a happy path: at least one negative per task; parity tests read the other shell's source; sabotage every new guard once (CLAUDE.md section 4 rule 2), in worktrees outside the checkout through `.drafts/d234/sab.py` (`/private/tmp/skipti-d234-tN-ios|android`); anchors match exactly once or the run stops; a compile error is the wrong red; exactly the expected tests red; restore and `cmp`.
- iOS tests: boot `AFAF4221-F35B-4CD6-8ED9-A4AFD84C6D51` once before a series (`xcrun simctl boot ... || true`); every `xcodebuild test` passes `-collect-test-diagnostics never -parallel-testing-enabled NO`; shut it down when the iOS lane ends. Android: `zsh -lic './gradlew ... --no-watch-fs'`; check result XML mtimes before quoting a tally.
- Commits: explicit paths only; `git status --porcelain` and `git diff --cached --stat` before every commit (refuse and report if the index holds a file you did not stage); subject ends `[skip ci]`; **no attribution of any kind** (no Co-Authored-By, no "Generated with"); after committing, `git log -1 --format=%B | grep -ciE 'co-authored|generated with'` must print `0`.
- Never `git stash`, `git reset`, `git checkout -- <file>`, `git restore`, `git add -A`, `git add .`, `git commit -a`; never switch branches. Two tasks running at once (T2 with T3, T4 with T5) touch disjoint files; each commits only its own paths.

    private fun summaryWidth(parts: List<String>, theme: AppTheme): Double {
        val text = parts.joinToString(Separator.meta(theme))
        val styled = java.text.AttributedString(text)

        if (theme == AppTheme.NORSE) {

            if (line.isEmpty() || measure(longer) <= room) line = longer else { lines += line; line = word }

        return lines
