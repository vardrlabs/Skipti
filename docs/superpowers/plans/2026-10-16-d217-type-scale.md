# D-217 One Type Scale (iPhone's Way) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Both phones draw the same sizes, the same titles and bars, and the same type roles, iOS's values being the scale.

**Architecture:** One size table per shell (`TypeScale` in Swift and Kotlin, compared across shells by a parity test that reads the Swift file, like `PaletteParityTest`), a `name` type role on both shells, every call site of the sixteen size families moved to the table, and on Android one bar component (`SkiptiBar`: tab root, pushed, sheet) that twins iOS's navigation bar and replaces `ScreenHeader` and every per-screen header.

**Tech Stack:** SwiftUI / UIKit (iOS 17+), Jetpack Compose (Android), XCTest, JUnit.

Spec: `docs/superpowers/specs/2026-10-16-d217-type-scale-design.md` (the founder's decisions of 2026-10-16). Measurements:
`.drafts/d215/look/look-report.md` section 7 (the size table). Screen inventory: `.drafts/d217/screens.md`.

## Global Constraints

- iPhone and Android must look identical, type included (CLAUDE.md Twins). Where they differ, iOS's value is the scale
  (founder, 2026-10-16), except where the spec names the Look Book's value (greeting 700 and Norse +.02em, You name 700
  and handle 500, tile initials display 700, the ornament).
- Sizes (points on iOS, sp on Android): large title 34; inline title 17; date line 14 (kicker role); hero amount 44, 700;
  hero "You'll get back" 15; by-group "Settled" 13; Expenses group header count 13; detail lines 14 (group cards, "People
  in X", waiting line, group page detail, expense attribution, the You sub-screens' seven sites); stat tile value 16, 600,
  shrinking to fit; Settle intro and explainer 15; share-input amount 15; avatar initial 0.38 of the avatar.
- Titles keep `TitleStyle`'s weight (700, Vardr Labs 600) and tracking (-0.01 em; Norse +0.03; Vardr Labs -0.02).
- Android: no fixed `lineHeight` on `Type.body` or its copies (natural height, as iOS); row titles at a line limit end in
  an ellipsis (`TextOverflow.Ellipsis`).
- Chevrons: Lucide `chevron-left` and `chevron-right`, copied VERBATIM from upstream (read the SVG at
  `https://unpkg.com/lucide-static@latest/icons/chevron-left.svg` and `.../chevron-right.svg` with WebFetch; reading only,
  nothing executed), listed in NOTICE in the same commit (NOTICE's Lucide entry: "eight drawings" becomes ten).
- No em dashes anywhere (code, comments, copy, commits). Commits end `[skip ci]`; explicit paths only;
  `git diff --cached --stat` before every commit; no attribution of any kind.
- Onboarding is out of scope (the founder, 2026-10-16): no screen work on first-run surfaces beyond what shared pieces
  change.
- Looks only on throwaway devices against the local emulators: iOS `d214-look` (BDC0AE93-1CA7-4EE6-9C52-FA44D7C01F92);
  Android a NEW throwaway AVD `d217-look` (API 34 `system-images;android-34;default;arm64-v8a`, `-gpu host`), deleted
  after. Never AFAF4221, EB725812 or `skipti-shots`. Boot the iOS test simulator before a series of `xcodebuild test`

  same order.

- Kotlin `Type.name(dark: Boolean, size: Int = 16): TextStyle`: `family(Role.BODY)`, `weightFor(Role.BODY, 600)`, color
  `Tok.text(dark)`, no fixed line height.
