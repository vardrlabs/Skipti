# D-230 Held Places: the Server Says Who Holds a Place, Core Believes Only That (Implementation Plan)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A phone-written `claim` can no longer take or deny anyone's place or history in a group: every place an
account holds is marked by the server (`heldPlace`, `held: true`), and core treats that mark as final for the member
and for the id, so CLOUD-SECURITY G-08 closes to one narrow race. Spec: `docs/superpowers/specs/2026-10-18-d230-held-places.md`
(approved by the founder 2026-10-18).

**Architecture:** D-229's marked alias, applied to the place itself. A new group op `heldPlace {group, member, you}`
that phones build and never upload; the server writes it marked after verifying the caller holds `member` (`holderIn`)
and owns `you` (its participant id or its own personal log, nobody else's). Two writers: a new callable `sharePlaces`
(the `AliasShare` loop's twin on both shells, once per place) and `acceptInvite` (an optional built record, written in
the join's transaction). Core: per member the LATEST marked held place stands; every unmarked claim on a held member
with another id, or naming a held id on another member, is void (reported `contested`); decisions 44 to 51 run over
what is left.

**Tech Stack:** Rust core + UniFFI (bindings regenerated once, in Task 1), Cloud Functions (plain JS, node:test
against the emulators), SwiftUI + XCTest, Jetpack Compose + JUnit.

## Design decisions carried into the tasks

- D1. A `heldPlace` for a member nobody added waits (`pending`), as a `placeAlias` does.
- D2. Per member, the latest marked held place by record identity stands; an older one is reported `contested`
  (superseded, never applied silently). The server bounds a marked record's HLC to 10 minutes of its clock, so
  record identity is server order in practice (decision 54).
- D3. A held place whose `you` is a raw member other than `member` is `contested` (the server never writes one).
- D4. A held member's winning claim IS the held place: `claims[member] = { member, you: held.you, devices }`, seeded
  before the claims pass with `claimed_at` = the held record's identity; a later same-`you` claim adds devices as
  today; a claim with another `you` on that member is void (`contested`); a claim on ANY member naming an id that a
  held place gives to a different member is void (`contested`). Void claims never enter `b.claims`, so decisions 44,
  47, 49 to 51 see only what counts.
- D5. A marked `placeAlias` naming a held id for a different member is `contested` (a held place says whose the id
  is; an alias only where it reads).
- D6. `placing`: before rule 2, the present member whose held place names one of `mine`. `you_as` unchanged
  (0.4.0 and 0.5.0 builds read only claim aliases; the seeded claim gives the alias as the phone's own claim did).
- D7. `sharePlaces` wants, per group with a `place` that is not read-only, `(place, you.id)` unless `held` already
  lists exactly that pair; answered keys `group:member:you`. A `RESOURCE_EXHAUSTED` or offline answer is asked again
  at the next push; `invalid-argument` is done.
- D8. The join passes one built record whenever the account has a "you"; the Function writes it marked only when every
  check holds and never fails the join over it (decision 56). The phone's unmarked claim is still written at join
  (0.4.0 readers).

```js
const MAX_HELD = 50; // sharePlaces: what one call asks

/** D-230: null when `records` (1 to 50) are each a heldPlace op (type 3)
 *  with exactly `op`, `group`, `member` and `you`, three 32-hex ids (`you`
 *  MAY equal `member`: a creator's raw place), well formed, no record id
 *  twice and no (group, member) twice; otherwise 'records'. Whether the
 *  caller holds the place and owns the id is decided per record by the
 *  Functions, never here. */
export function checkHeldRecords(records) {
  if (!Array.isArray(records) || records.length < 1 || records.length > MAX_HELD) return 'records';
  const ids = new Set();
  const pairs = new Set();
  for (const r of records) {
    if (!recordShape(r) || ids.has(r.id) || r.type !== '3') return 'records';
    ids.add(r.id);
    const b = json(r.payload.blob);
    if (b?.op !== 'heldPlace') return 'records';
    if (Object.keys(b).some((k) => !['op', 'group', 'member', 'you'].includes(k))) return 'records';
    if (![b.group, b.member, b.you].every((v) => typeof v === 'string' && HEX32.test(v))) return 'records';
    const pair = `${b.group}:${b.member}`;
    if (pairs.has(pair)) return 'records';
    pairs.add(pair);
  }
  return null;
}
```

```js
/** D-230: the checks a held place shares between sharePlaces and the join:

async function checkHeldId(r, a, uid, yous, refuse) {
  if (Math.abs(r.hlc.millis - Date.now()) > HELD_SKEW_MS) throw refuse();

}

    return logs.get(u);

    const a = groups.json(r.payload.blob);

      logger.warn('sharePlaces: a record was skipped', { code: e.code });
      skipped.push(r.id);
    }
  }
```

```swift
/// D-230: the server's word on who holds a place. After a push that reached the cloud, every place this account
/// holds that the group's log does not yet mark for this account's "you" is shared once as a `heldPlace` the
/// `sharePlaces` Function verifies and writes marked (`held: true`); core then treats it as final for the member
/// and the id (CLOUD-SECURITY G-08). The AliasShare contract: asked once per (group, place, you), answers
/// remembered, a failed call or the daily quota asked again at the next push, a refused call done.
enum PlaceShare {
    /// "group:member:you" lines: the triples the cloud has answered.
    static let answeredKey = "place.share.answered"
    /// The callable takes 1 to 50 records.
    static let callMax = 50

    /// In `groupId`, the place `memberId` is held by this account's id `youId`.
    struct Held: Equatable {
        let groupId: String
        let memberId: String
        let youId: String

        var key: String { groupId + ":" + memberId + ":" + youId }
    }

    // MARK: - Pure parts

    /// The places to ask for: per group with a place that is not a read-only copy (`readOnly`), (place, you) unless
    /// the group's marked held places list exactly that pair, less the keys already `answered`.
    static func wanted(_ p: GroupsProjectionOut, readOnly: Set<String>, answered: Set<String>) -> [Held] {
        guard let you = p.you?.id else { return [] }
        return p.groups.compactMap { g -> Held? in
            guard let place = g.place, !readOnly.contains(g.group.id) else { return nil }
            if g.held.contains(where: { $0.memberId == place && $0.youId == you }) { return nil }
            let held = Held(groupId: g.group.id, memberId: place, youId: you)
            return answered.contains(held.key) ? nil : held
        }
    }

    /// One `heldPlace` record per place, stamped and authored by this phone through `groupOpRecord` (the group's
    /// scope), NOT put into the vault.
    static func records(
        store: LedgerStore, places: [Held], nowMs: UInt64 = UInt64(Date().timeIntervalSince1970 * 1000)
    ) throws -> [RecordWire] {
        let device = try LedgerStore.Sync.deviceId(store)
        return try places.map { held in
            try LedgerStore.Sync.groupOpRecord(
                .heldPlace(groupId: held.groupId, memberId: held.memberId, youId: held.youId),
                hlc: try LedgerStore.Sync.nextHlc(store, nowMs: nowMs), deviceId: device)
        }
    }

    /// The records `share` sends, one group at a time: a group whose record core cannot build is skipped and asked
    /// again at the next push; every other group's still goes.
    static func recordsByGroup(
        store: LedgerStore, places: [Held], nowMs: UInt64 = UInt64(Date().timeIntervalSince1970 * 1000)
    ) -> [(held: Held, record: RecordWire)] {
        places.compactMap { held in
            guard let built = try? records(store: store, places: [held], nowMs: nowMs), built.count == 1 else { return nil }
            return (held: held, record: built[0])
        }
    }

    /// The `sharePlaces` callable's data: the D-210 record shape.
    static func callData(_ records: [RecordWire]) -> [String: Any] {
        ["records": Removal.payload(records)]
    }

    /// The record ids the reply answered (`shared` and `skipped`).
    static func replied(_ reply: [String: Any]) -> Set<String> {
        Set(((reply["shared"] as? [String]) ?? []) + ((reply["skipped"] as? [String]) ?? []))
    }

    /// AliasShare's answers, the same meaning.
    typealias Answer = AliasShare.Answer

    static func answer(_ error: Error?) -> Answer { AliasShare.answer(error) }

    // MARK: - The answered triples

    static func answered(_ store: LedgerStore) -> Set<String> {
        guard let data = (try? store.kvGet(key: answeredKey)) ?? nil, !data.isEmpty else { return [] }
        return Set(String(decoding: data, as: UTF8.self).split(separator: "\n").map(String.init))
    }

    static func saveAnswered(_ store: LedgerStore, _ keys: Set<String>) throws {
        try store.kvSet(key: answeredKey, value: Data(keys.sorted().joined(separator: "\n").utf8))
    }

    // MARK: - The job

    /// The call, replaceable by the tests. Seam: tests only; production never reassigns.
    @MainActor static let realSend: ([String: Any]) async throws -> [String: Any] = { data in
        try await CloudFunctions.call("sharePlaces", data)
    }
    /// Tests only; production never reassigns.
    @MainActor static var send = realSend

    /// After a push that reached the cloud: asks for every wanted place of a group this phone knows is in the
    /// cloud (`CloudRecords.groupsUp`), in calls of at most 50, and remembers what the cloud answered.
    @MainActor @discardableResult
    static func share(store: LedgerStore, nowMs: UInt64 = UInt64(Date().timeIntervalSince1970 * 1000)) async -> Answer {
        guard let up = try? CloudRecords.groupsUp(store), let p = try? LedgerStore.Sync.projectGroups(store) else {
            return .later
        }
        let want = wanted(p, readOnly: Set(store.readOnly().keys), answered: answered(store))
            .filter { up.contains($0.groupId) }
        guard !want.isEmpty else { return .done }
        let pairs = recordsByGroup(store: store, places: want, nowMs: nowMs)
        guard !pairs.isEmpty else { return .later }
        let built = pairs.map { $0.record }
        let keyOf = Dictionary(pairs.map { (CloudRecords.documentId($0.record), $0.held.key) },
                               uniquingKeysWith: { a, _ in a })
        for start in stride(from: 0, to: built.count, by: callMax) {
            let chunk = Array(built[start..<min(start + callMax, built.count)])
            var reply: [String: Any] = [:]
            var failure: Error?
            do { reply = try await send(callData(chunk)) } catch { failure = error }
            let ids: Set<String>
            switch answer(failure) {
            case .done: ids = replied(reply)
            case .refused: ids = Set(chunk.map(CloudRecords.documentId))
            case .later: return .later
            }
            var done = answered(store)
            ids.compactMap { keyOf[$0] }.forEach { done.insert($0) }
            try? saveAnswered(store, done)
        }
        return .done
    }
}
```
