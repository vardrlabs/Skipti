# E2 motion (D-214): the themes' living art, Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the art move where the spec says it moves: Aurora's curtains over a starry night (dark) or an arctic dawn (light) behind every page and in every Aurora hero, Norse's runes rising behind every page with a still watermark and frame in the hero, Vardr Labs' currency signs drifting across the hero, and the hex bolt's 30-degree turn; one engine per shell, 30 fps at most, a designed still frame under Reduce Motion or Low Power, every pair the moving art can reach measured.

**Architecture:** Every animation is a pure function of time and a fixed seed (`ThemeMotion.swift` / `ThemeMotion.kt`) returning the positions, sizes, rotations and opacities of its parts; goldens come from `.drafts/d214/motion.py`, which ports the Look Book's own formulas. One renderer per shell draws them: iOS `ArtCanvas` (`TimelineView(.animation(minimumInterval: 1/30, paused:))` + `Canvas`), Android `Modifier.artCanvas` (a Compose draw modifier driven by `withFrameNanos`, throttled to 30 fps). A pure `MotionClock.shouldTick(reduceMotion:lowPower:active:)` decides whether either ticks; when it does not, the renderer draws the still frame. The page grounds go through the existing `auroraBackground` (iOS 51 sites, Android 21), the heroes through one `HeroArt` per shell used by Overview's hero and Sign-in's hero.

**Tech Stack:** SwiftUI (`TimelineView`, `Canvas`, `GraphicsContext`), Foundation (`ProcessInfo` Low Power); Jetpack Compose 1.12 (`drawWithCache`, `drawText`, `withFrameNanos`, `BlendMode`, `RenderEffect` blur on API 31+), `PowerManager`, `Settings.Global`; Python 3 (`.drafts/d214/motion.py`). No new dependency.

**Spec:** `docs/superpowers/specs/2026-10-15-e2-theme-art-design.md` section 2 (approved 2026-10-15) and the founder's decisions of 2026-10-15 on strength (below). Visual reference: the Look Book v2.1 (`.drafts/lookbook/skipti-lookbook.html`, lines 195-226 and 340-460) and the strength demo https://claude.ai/artifact/Qx6Z9d11ExHh7QniZ3NLKF (`.drafts/d214/curtains-demo.html`).

**Branch:** `e2-motion` from main. D-number **D-214**. Drafts in `.drafts/d214/`.

## The founder's decisions on strength (2026-10-15, popup over the demo)

The Look Book's curtains break the floors (a dark page's title at 1.1:1, the hero's amount at 1.1:1). The founder chose:
1. **Aurora pages**: text sitting on the page art keeps text 7:1 and section labels 4.5:1. Faint text and accent text sitting directly on the Aurora page ground take the label colour, through two new five-set tokens: `groundFaint` (Aurora light `#4D615E`, Aurora dark `#8FA9A4`, Norse `#8D8675`, Vardr Labs light `#5E6C75`, Vardr Labs dark `#7A8995`) and `groundAccent` (`#4D615E`, `#45E6B0`, `#CDA750`, `#4C6172`, `#9DB0BF`): in Aurora light both are the label colour; in Aurora dark the accent passes and stays; every other theme keeps `textFaint` / `accent`.
2. **Aurora hero**: the Look Book's curtains and stars at full strength, today's layout (the founder, 2026-10-15, after the demo's "Where the hero's text sits" row): he accepted that at the curtains' lowest swing the hero's first line and amount drop to about 1.7:1 (the bright band lives in the top third of the hero; below 37% of its height every line keeps 7:1). The moving-art floor test therefore measures the Norse and Vardr Labs heroes and pins the Aurora hero's strengths; it does not floor Aurora's hero text.

```swift
/// Vardr Labs' currency signs drifting across the hero (the Look Book's seeded field).
enum CurrencyField {
    struct Floater: Equatable {
        let glyph: String
        let bx, by, ax, ay, sx, sy, ph: Double
        let size: Int
        let rot: Double
        let cyan: Bool
        let depth: Double

    static let signs = ["$", "\u{20B9}", "\u{20AC}", "\u{00A3}", "\u{00A5}", "\u{20A9}", "\u{20BD}", "\u{0E3F}", "\u{20BA}", "\u{20A6}", "\u{20B1}",

    /// The majors: (bx, by, size, cyan).
    static let majors: [String: (Double, Double, Int, Bool)] = [
        "\u{20B9}": (0.80, 0.32, 40, true), "$": (0.62, 0.68, 30, false), "\u{20AC}": (0.90, 0.72, 28, false),
        "\u{00A3}": (0.70, 0.18, 24, false), "\u{00A5}": (0.94, 0.40, 24, false),
    ]
    /// The still frame's time (the Look Book's reduced-motion frame).
    static let still: Double = 4

    /// The first `n` draws of Park-Miller from seed 7.
    static func draws(_ n: Int) -> [Double] {
        var seed: Int64 = 7
        return (0..<n).map { _ in
            seed = (seed * 16807) % 2_147_483_647
            return Double(seed - 1) / 2_147_483_646
        }
    }

            }

        }
    }()

        let y = f.by + f.ay * cos(t * f.sy + f.ph * 1.3)
        let calm = min(1, max(0.28, (x - 0.2) / 0.45))
        return Pose(x: x, y: y, rotation: f.rot + 0.12 * sin(t * 0.3 + f.ph), alpha: (0.16 + 0.5 * f.depth) * calm,
                    size: (Double(f.size) * (0.7 + 0.5 * f.depth)).rounded())
    }
}
```

```swift
/// One renderer for all moving art: a Canvas redrawn by a TimelineView at 30 fps at most, paused (drawing the still
/// frame) when shouldTick says so. Decorative: hidden from VoiceOver and from touches.
struct ArtCanvas: View {
    let still: Double
    let draw: (inout GraphicsContext, CGSize, Double) -> Void

    @Environment(\.accessibilityReduceMotion) private var reduceMotion
    @Environment(\.scenePhase) private var phase
    @Environment(\.artVisible) private var visible
    @State private var onScreen = false

    var body: some View {
        let tick = MotionClock.shouldTick(reduceMotion: reduceMotion, lowPower: PowerState.shared.lowPower,
                                          active: phase == .active && visible && onScreen)
        TimelineView(.animation(minimumInterval: 1 / MotionClock.fps, paused: !tick)) { timeline in
            Canvas { ctx, size in
                draw(&ctx, size, tick ? timeline.date.timeIntervalSinceReferenceDate : still)
            }
        }
        .onAppear { onScreen = true }
        .onDisappear { onScreen = false }
        .accessibilityHidden(true)
        .allowsHitTesting(false)
    }
}

/// The drawing of each art layer, shared by the page grounds and the heroes.
enum ArtDraw {
    private static func color(_ s: Curtains.Stop) -> Color {
        Color(red: s.r / 255, green: s.g / 255, blue: s.b / 255).opacity(s.alpha)
    }

    /// The night sky or the dawn is the caller's; this draws the stars (night) and the three curtains.
    static func curtains(_ ctx: inout GraphicsContext, _ size: CGSize, _ t: Double, night: Bool,
                         curtainStrength: Double, starStrength: Double) {
        if night && starStrength > 0 {
            for s in Stars.all {
                let r = CGFloat(s.radius)
                ctx.fill(Path(ellipseIn: CGRect(x: size.width * s.x - r, y: size.height * s.y - r, width: r * 2, height: r * 2)),
                         with: .color(.white.opacity(s.alpha * starStrength)))
            }
        }
        for (i, spec) in Curtains.specs.enumerated() {
            let p = Curtains.pose(i, t)
            var layer = ctx
            layer.blendMode = night ? .screen : .multiply
            layer.opacity = (night ? spec.nightOpacity : spec.lightOpacity) * curtainStrength
            layer.addFilter(.blur(radius: night ? 9 : 14))
            let rect = CGRect(x: 0, y: 0, width: size.width * p.width, height: size.height * p.height)
            // The curtain's own transform: to its place, then the sway's scale and skew about its centre.
            layer.translateBy(x: size.width * p.x + rect.width / 2, y: size.height * p.y + rect.height / 2)
            layer.concatenate(CGAffineTransform(a: p.sx, b: 0, c: tan(p.skewDegrees * .pi / 180) * p.sx, d: p.sy, tx: 0, ty: 0))
            layer.translateBy(x: -rect.width / 2, y: -rect.height / 2)
            let shading = GraphicsContext.Shading.linearGradient(
                Gradient(stops: spec.stops.map { .init(color: color($0), location: $0.at) }),
                startPoint: CGPoint(x: 0, y: 0), endPoint: CGPoint(x: 0, y: rect.height))
            // The streaks: the full curtain at the pattern's average, then its two bright bars (2 pt and 1 pt of 11).
            var base = layer
            base.opacity *= 0.45
            base.fill(Path(rect), with: shading)
            var bars = Path()
            var x: CGFloat = 0
            while x < rect.width {
                bars.addRect(CGRect(x: x, y: 0, width: 2, height: rect.height))
                bars.addRect(CGRect(x: x + 6, y: 0, width: 1, height: rect.height))
                x += 11
            }
            var bright = layer
            bright.opacity *= 0.55
            bright.clip(to: bars)
            bright.fill(Path(rect), with: shading)
        }
    }

    static func runes(_ ctx: inout GraphicsContext, _ size: CGSize, _ t: Double, still: Bool, strength: Double) {
        for i in 0..<RuneDrift.count {
            let p = still ? RuneDrift.still(i, in: size) : RuneDrift.pose(i, t, in: size)
            guard p.opacity > 0 else { continue }
            let colour = ThemeArt.color(p.silver ? "norseSilver" : "diamondTop")
            var layer = ctx
            layer.opacity = p.opacity * strength
            layer.translateBy(x: p.x, y: p.y)
            layer.rotate(by: .degrees(p.rotationDegrees))
            layer.draw(Text(verbatim: p.glyph).font(.system(size: p.size)).foregroundColor(colour), at: .zero)
        }
    }
}
```

```kotlin
/** D-214: whether art ticks here: not under the system's "remove animations" (animator duration scale 0) or battery
 *  saver, and only while the screen is resumed. Read again on every resume and on the power-save broadcast. */
@Composable
fun rememberShouldTick(): Boolean {
    val context = LocalContext.current
    val lifecycle = androidx.lifecycle.compose.LocalLifecycleOwner.current.lifecycle
    var resumed by remember { mutableStateOf(lifecycle.currentState.isAtLeast(Lifecycle.State.RESUMED)) }
    var reduce by remember { mutableStateOf(animatorsOff(context)) }
    var lowPower by remember { mutableStateOf(powerSave(context)) }
    DisposableEffect(lifecycle, context) {
        val observer = LifecycleEventObserver { _, event ->
            resumed = lifecycle.currentState.isAtLeast(Lifecycle.State.RESUMED)
            if (event == Lifecycle.Event.ON_RESUME) { reduce = animatorsOff(context); lowPower = powerSave(context) }
        }
        val receiver = object : BroadcastReceiver() {
            override fun onReceive(c: Context, i: Intent) { lowPower = powerSave(context) }
        }
        lifecycle.addObserver(observer)
        ContextCompat.registerReceiver(context, receiver, IntentFilter(PowerManager.ACTION_POWER_SAVE_MODE_CHANGED), ContextCompat.RECEIVER_NOT_EXPORTED)
        onDispose { lifecycle.removeObserver(observer); context.unregisterReceiver(receiver) }
    }
    return MotionClock.shouldTick(reduceMotion = reduce, lowPower = lowPower, active = resumed)
}

private fun animatorsOff(c: Context) =
    Settings.Global.getFloat(c.contentResolver, Settings.Global.ANIMATOR_DURATION_SCALE, 1f) == 0f

private fun powerSave(c: Context) = (c.getSystemService(Context.POWER_SERVICE) as PowerManager).isPowerSaveMode

/** One renderer for all moving art, the twin of iOS's ArtCanvas: a draw modifier fed by the frame clock at 30 fps at
 *  most; when it does not tick it draws [still]. Decorative: no semantics. */
fun Modifier.artCanvas(still: Double, draw: DrawScope.(t: Double) -> Unit): Modifier = composed {
    val tick = rememberShouldTick()
    var t by remember { mutableDoubleStateOf(still) }
    LaunchedEffect(tick) {
        if (!tick) { t = still; return@LaunchedEffect }
        var last = 0L
        while (true) {
            withFrameNanos { now ->
                if (now - last >= 1_000_000_000L / MotionClock.FPS.toLong()) { last = now; t = now / 1e9 }
            }
        }
    }
    drawBehind { draw(t) }
}
```

```swift
                }
```
